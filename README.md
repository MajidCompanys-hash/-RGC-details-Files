إدارة مشاريعي (بقالة + كوي ملابس) — سلطنة عمان

تطبيق ويب في ملف واحد (index.html) بلا مكتبات خارجية، بخمس صفحات وشريط تنقل سفلي، لكل مشروع بياناته المستقلة.

الصفحات





الرئيسية: إيرادات ومصروفات وصافي ربح، يومي وأسبوعي وشهري وسنوي، مع رسم بياني ومقارنة بالفترة السابقة وبتقدير دراسة الجدوى، ونموذج تسجيل عملية، وشريط تنبيهات.



العمال: ملف لكل عامل، مستنداته مع تواريخ الانتهاء والتنبيه، مهامه، وإرفاق الملفات ومعاينتها وطباعتها وإرسالها.



الشركة: مستندات الشركة والسجل التجاري والتراخيص مع تاريخ الانتهاء والتجديد والإرفاق والطباعة وتصدير التذكيرات إلى تقويم الجوال (.ics).



العمليات: التقارير الشهرية (طباعة وCSV)، المهام وخطة 90 يوماً، دراسة الجدوى، قائمة الالتزامات النظامية.



الإعدادات: البحث الشامل، مدة التنبيه، المظهر، مزامنة Google Drive، نسخة احتياطية كاملة.

التشغيل والنشر

افتح index.html مباشرة، أو انشره على GitHub Pages: ارفع الملفين، ثم Settings ثم Pages، واختر Branch main والمجلد / (root).

أين تعدّل





المهام والمستندات: const P (قسم g للبقالة وk للكوي).



بنود الإيرادات والمصروفات: CIN وCOUT.



القانون: LGC وLG. أنواع التراخيص: LT. أنواع مستندات العمال: DT.



حقول دراسة الجدوى: FZ وFM.



نموذج البيانات في localStorage بالمفتاح bizplan2: لكل مشروع tx (العمليات) وlic وw وfl وfz وcustom وdone.

المزامنة مع Google Drive

تعمل فقط بعد النشر على GitHub Pages (رابط https). تُحفظ البيانات في مجلد خاص بالتطبيق داخل Drive (drive.appdata) ويمكن تشفيرها بكلمة سر.

إعداد لمرة واحدة:





أنشئ مشروعاً في Google Cloud Console وفعّل Google Drive API.



من شاشة الموافقة (OAuth consent screen) اختر External، وأضف بريدك كـ Test user.



أنشئ OAuth client ID من نوع Web application.



في Authorized JavaScript origins ضع https://USERNAME.github.io (بدون مسار).



الصق Client ID في الإعدادات داخل التطبيق (يُحفظ في المتصفح، ولا ترفعه للمستودع).

«رفع» يستبدل نسخة Drive بما على الجهاز، و«تنزيل» يستبدل ما على الجهاز بنسخة Drive. تنتهي جلسة الاتصال بعد نحو ساعة. إن نسيت كلمة سر التشفير فلا يمكن استرجاع النسخة.

الملفات المرفقة





تُحفظ في المتصفح (IndexedDB) ولا تُرفع لأي خادم. الصور تُصغَّر تلقائياً، وحد الملف 20 ميغابايت.



مزامنة Drive تنقل بيانات المستندات وأسماء الملفات فقط، لا الملفات نفسها.



مسح بيانات المتصفح يحذف الملفات، فاحتفظ بنسخ أصلية.



المشاركة (📤) تعتمد على قائمة المشاركة في الجوال، وقد لا تعمل في بعض متصفحات الكمبيوتر؛ استخدم «حفظ» ثم أرسل الملف.
